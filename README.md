# Tecnovia bloque 3 - entornos de desarrollo y git 

## descripcion
proyecto Java para saludo personalizado, con una suma, para el proyecto unidad3

## Requisitos 
- IntelliJcommunity: 2024
- VS Code: ultima version
- JDK (Adoptium): 17 LTS
- Python: 3.11+
- Git: 2.x
- Githut

## Instalacion
1. Clona el repositorio en tu maquina local:
   git clone [https://github.com/triguerosluna-code/tecnovia-bloque3.git](https://github.com/triguerosluna-code/tecnovia-bloque3.git)

## Uso
para compilar y ejecutar el proyecto desde la terminal
